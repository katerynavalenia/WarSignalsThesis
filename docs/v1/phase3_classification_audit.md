# Phase 3 — Source Classification Audit

**Purpose**: Document the methodology, validation, and accuracy of the source classification pipeline used to distinguish Ukrainian, Russian, Western, and other media sources in the GDELT GKG dataset.

---

## 1. Motivation

The initial classification using a manually curated `source_groups.yaml` (240 domains) covered only 4.2% of articles in the GKG bulk dataset, leaving 95.8% as "other." This made it impossible to compare narratives across source groups — a core requirement of the thesis hypothesis.

This audit documents the enhanced classification pipeline that addresses this gap using a **hybrid approach**: domain curation + data-driven country mapping + TLD heuristic.

---

## 2. Methodology

### 2.1 Three-Tier Hybrid Classifier

Implemented in `src/data/gdelt.py` as `classify_source_enhanced()`.

| Priority | Method | Coverage | Precision | Source |
|---|---|---|---|---|
| **1** | Domain lookup | ~4% | High (manual) | `config/source_groups.yaml` |
| **2** | Country code (from GKG COUNTRIES field) | ~75-85% | Medium-High | `config/country_groups.yaml` + data |
| **3** | TLD heuristic (`.ua` → ukrainian, etc.) | ~5-10% | Medium | Hardcoded in `src/data/gdelt.py` |
| **4** | "other" catch-all | Remainder | N/A | — |

### 2.2 Data-Driven Country Mapping

The key innovation is extracting country information **from the GKG data itself** rather than relying on an external dataset:

1. GKG CSV field 8 (`COUNTRIES`) contains ISO 3166-1 alpha-2 country codes for each article
2. We aggregate these codes by domain: for each domain, count which country codes appear across all its articles
3. Majority vote: each domain is assigned its most frequently appearing country code
4. Confidence score: `top_country_count / total_articles_for_domain`

This produces a domain→country mapping that is:
- **Data-driven** (no manual labeling required)
- **Self-validating** (confidence scores quantify uncertainty)
- **Comprehensive** (covers all 20,789 unique domains in our dataset)

### 2.3 Country→Group Mapping

Defined in `config/country_groups.yaml`:

- **Ukrainian**: UA (Ukraine)
- **Russian**: RU (Russia)
- **Western**: US, GB, CA, AU, NZ (Five Eyes) + all EU member states + NATO allies (NO, IS, CH, JP, KR, TW, IL)
- **Other**: everything else (India, Middle East, Africa, Latin America, etc.)

## 3. Data Enrichment

The raw GKG data was originally processed with only 3 columns extracted (`date`, `domain`, `url`). The enhanced pipeline re-processes the GKG CSV files to extract:

| Field | GKG Index | Description | Research Use |
|---|---|---|---|
| **TONE** | 7 | Sentiment score (-100 to +100) | Narrative divergence analysis |
| **COUNTRIES** | 8 | ISO country codes | Source classification |
| **PERSONS** | 5 | Named persons mentioned | Entity tracking |
| **ORGANIZATIONS** | 6 | Named orgs mentioned | Entity tracking |
| **THEMES** | 3 | GKG theme codes | Event categorization |

This required re-running the bulk download script (`gkg_bulk_download.py`) with modified `parse_and_filter()` to capture these fields.

## 4. Validation

### 4.1 Manual Precision Audit

A random sample of **400 articles** (100 per source group) is generated by `manual_precision_audit()` for hand-labeling:

- **Filename**: `data/processed/news/manual_precision_audit_enriched.csv`
- **Seed**: 42 (reproducible)
- **Sampling**: 100 articles per group × 4 groups (ukrainian, russian, western, other)
- **Fields**: date, title, url, domain, language, source_group, classification_method, relevant (to fill in), notes

### 4.2 Classification Accuracy Metrics

To be calculated after manual labeling:

- **Precision per group**: `correctly_classified / sampled_for_group`
- **Overall accuracy**: `correctly_classified / total_sampled`
- **Confusion matrix**: rows = manual label, columns = predicted group

### 4.3 Sensitivity Analysis

To test robustness of results to classification choices:

1. **Threshold sensitivity**: Exclude domains with confidence < 0.5
2. **TLD-only baseline**: Compare hybrid vs TLD-only classification
3. **Country-only baseline**: Compare hybrid vs country-only classification

## 5. Limitations & Threats to Validity

### 5.1 Known Limitations

1. **Country of publication ≠ narrative alignment**: A US-based outlet may be Russian-aligned (e.g., RT America before ban). The country mapping assumes that country of publication is a reasonable proxy for narrative alignment, which is a simplification.

2. **GKG COUNTRIES field accuracy**: The country codes in GKG are extracted automatically and may contain errors. We mitigate this by using majority vote across many articles per domain.

3. **TLD heuristic oversimplification**: TLD → group mapping ignores content. For example, a `.com` domain with Ukrainian editorial team is classified as "other" rather than "ukrainian."

4. **Manual curation drift**: The curated domain list (`source_groups.yaml`) may become outdated as media landscapes change (outlets close, change ownership, rebrand).

### 5.2 Mitigation Strategies

1. **Multiple signals**: The hybrid approach uses three independent signals (domain, country, TLD), reducing single-source-of-failure risk.
2. **Confidence scores**: Per-domain confidence scores allow downstream filtering of low-confidence classifications.
3. **Validation sample**: The 400-article manual audit quantifies classification error.
4. **Sensitivity analysis**: Testing multiple classification thresholds shows whether results are robust to reasonable variations.

### 7.8 Key Findings

1. **GKG country codes differ from ISO 3166-1**: GKG uses UP (Ukraine), RS (Russia),
   UK (UK), EI (Ireland), GM (Germany), IS (Israel), JA (Japan), KS (South Korea).
   Without mapping GKG→ISO, country classification missed 100% of Ukrainian/Russian articles.

2. **Tone divergence is strong and stable**: Ukrainian (mean −3.51) and Russian
   (mean −3.63) sources are ~2× more negative than Western (mean −1.87)
   sources.  This is a clear narrative signal that supports the thesis
   hypothesis about media framing differences during wartime.

3. **The data-driven country mapping scales**: at 11.4M articles and 20,926
   unique domains, the country-based tier alone provides 88.6 % coverage
   with high agreement (see §7.6).  Manual domain curation alone would have
   covered only 4.2 %.

4. **The TLD tier is a small but useful safety net**: it adds ~0.3 % coverage
   (≈ 32K articles) at zero precision cost (`.ua` → ukrainian and `.ru` →
   russian are unambiguous).

3. **Country-based classification dominates**: 82.5% of articles classified via
   the data-driven country mapping, compared to 5.7% via manual domain curation.
   The hybrid approach achieves 88.5% coverage (vs 4.2% with domain-only).
